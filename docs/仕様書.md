# 仕様書

## 全体構成

- 導入部
- 練習部
- 修行部
- 認定部
- 装飾部

全体的なデザインは時間がないため基本的に任せるが、以下の点を意識して欲しい

- 色数は少なくすること、色やアウトラインなどのスタイルは、できるだけ統一感をもたせ、1つのファイルを基準に設定できるようにすること。
- グラデーションはできるだけ用いないこと。
- コーディングの体験を邪魔しない程度にだが、少しゆるっとした雰囲気を基本スタイルとすること。修行と行っているが別にそんなに和ではない。ライトモードとダークモードを用意するとさらに良い。

## 導入部

- 黒い画面に、物語の導入としての文章（白色の文字）が徐々に（一文字ずつ）送られていく。（200字程度。もちろん改行も含む）
- 導入部の表示は教材を開いた最初の一回のみ。
- 最初だけかつ200字程度の文章なので、途中でスキップはできないようにする。
- あなたの見た目を選んでくださいのような表示があり、男か女か選ばせる（具体的な男・女という性名は使わない）

## 練習部

- 基本的には修行部と同じ
- 唯一違うのは手順がしっかり決められていること。修行部のやり方がわかるように、師匠の説明を見ながら手順を踏んで教材について学んでいく。

## 修行部

- スーパーマリオブラザーズシリーズによくあるような修行選択画面がある。修行情報として番号や修行名の他に難易度の星やクリア/未クリアなどがビジュアルや文字で表示される。既にクリアした修行とその1つ次の修行まで始めることが可能。なお、既にクリアした修行をやっても報酬が変化することはない。修行選択画面はホーム画面を兼ねている。そのため、装飾部へも行ける。
- 解説パートと課題パートに分かれる。
- コードエリアがよく出てくるが、共通する部分は、左に行番号や何かしらの画像アイコンが表示できることである。
- 解説パート
  - レイアウトは大きく縦に3分割され、左から順に文章解説エリア、お手本コードエリア、ビジュアルエリアである。ビジュアルエリアはさらに上から修行情報、キャンバス画面、コントロールパネル、師匠エリアに分かれる。
  - 文章解説エリアではHTMLテキストを表示して文章（または図）のコンテントを表示する。内容はお手本コードの記述と動作の解説を通じた、課題パートの前提知識解説となる。
  - お手本コードエリアではテキストエリアに文章が表示される。このコードエリアは課題パートのコード記述エリアとシステム的にほぼ同じものなので、システムの詳細はそちらを参照。そのため、元のコードを編集可能。編集したものはエリア下部のリセットボタンでいつでも元のお手本コードに直せる。これによってコードの理解を早めることを狙う。
  - 修行情報にはこの修行に関するデータ類（番号、修行名等）が簡潔に表示。
  - キャンバス画面では実行結果がHTML Canvasで表示される。キャンバスサイズについてはわかりやすい数を用いる。
  - コントロールパネルはお手本コードの通常実行・インタプリタ自動実行・インタプリタ手動実行・停止・再開・課題パートへの遷移等が可能。（インタプリタ実行については後ほど）
  - 師匠エリアは師匠の画像と師匠の台詞が表示可能。
- 課題パート
  - レイアウトは大きく左と右に分かれる。左は上一帯が問題エリア、左下がお手本コードエリア、右下がコード記述エリアとなっている。右はビジュアルエリアなので、解説パートのビジュアルエリアとほぼ同じ。
  - 解説パートのビジュアルエリアと違う点は、修行情報にさらにコード解放数/率が表示されることが一点、コントロールパネルにお手本実行（最初のみ有効）があるのと課題パートへの遷移がないこと。
  - お手本コードエリアは、データで指定されたいくつかの位置（8割程度の行）に行隠しが入っていて、クリックすると剥がれる（少しアニメーションする）。剥がすとコード解放率が上がる。コード解放率は「開いた行数/最初に行隠しが入った行数」である。お手本を見れば見るほど報酬が少なくなるので、できるだけ自力で解かせるという仕掛けである。
  - コード記述エリアにはユーザがコードを入力する。Enterで改行、タブでJavaScriptコードにインデントを入れることができる（逆インデントはShift-Tab）。入力補完や正確なシンタックスハイライトはコストを考え入れないが、シンタックスハイライトは正確な正規表現などを使って基本的なものは可能にする。インタプリタ実行やエラーのときはその行（実行中の行やエラー行）がハイライトされる機能もあると良い。
- 実行形式
  - 前提：コード記述エリアに書くコードは全てではなく、全体のコードの中に埋め込むようにする。この全体のコードと埋め込み箇所は柔軟性をもたせるため各修行毎に変更も可能にすると良い。
  - 通常実行：JavaScriptをそのまま埋め込むなどして（少し安全性は考えてほしいが）全体コードを実行しキャンバス画面に表示。
  - インタプリタ実行：JS-Interpreter等を使い、インタプリタ実行を一行ずつ行ってキャンバスに表示。コード記述エリアでどの行が実行されているか閲覧可能。インタプリタ実行中は師匠エリアを消してその代わりに変数の情報を表示するエリアを置く。
- 修行をクリア（達成）したら、自動でクリア画面が表示。クリアのお祝いメッセージと、コード解放率、クリックで開けられる宝箱が複数個と、次または修行選択画面へのボタンが表示。宝箱はコード解放率が1/3未満で1つ、コード解放率が2/3未満で2つ、コード解放率がそれ以上で3つ出てくる。中身は修行に紐づいたアイテム3つ。つまり、修行ごとに最大3つアイテムがコレクションに追加される。

## 認定部

- 認定証を一枚の画像として表示する。（一枚の画像にするのは、後から全体を差し替えやすいため。ここは全体報酬なので心を込めて私が作りたい）
- ハッピーな演出がある。
- スクショを撮られることを想定し、またスクショを推奨する文章や画像を置く。

## 装飾部

- アイテムを使ってキャラクターやその周りをデコレーションできる。
- コレクションを閲覧できる他、コレクションからアイテムを選んで、画面上に配置できる。
- 配置の際は移動・回転・拡縮・削除等が一般的なツールのような簡単操作で可能。
- 配置情報もローカルストレージに簡潔に保存する。
- スクショされることを想定する。
