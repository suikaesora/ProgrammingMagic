# プロジェクト説明

## 概要

- 卒業論文のための制作物。テーマは「ID(インストラクショナル・デザイン)に基づいた『プログラミング』が 学習できるWeb 教材制作」である。卒業論文の成果としてはこの制作物の他に紙数十枚分の論文が必要だが、ここでは対象にしない。
- 制作するものはWebプログラミング学習教材で、技術的にはHTML+JS+CSSのみの静的なWebアプリケーションとする。ユーザが入力するのはJavaScriptコード。
- リリースはGitHubPagesで行う。リリース作業は制作物の完成後に私が人の手で行う。
- ブラウザのローカルストレージを利用し、学習の進捗状況・アイテムのコレクション情報・キャラ画面の配置情報などを保存する。
- Web教材として標準的なブラウザに対応させる。対応は主要な関心事ではないので、無理にではない。
- 時間が不足しているため、Claude Codeを用いた全面的なバイブコーディングにより、仕様を元としたシステムを本番環境で先に作ってもらい、その後にそれぞれの段階の課題内容や文章内容を私が人の手で入力する。そのため、Claude Codeには仕様を元に基盤のシステムを拡張性高く作ってもらいたい。さらに、課題内容や文章内容を仮で入れたサンプルシーンも作ってもらえるとありがたい。
- 教材のターゲットはチームでゲームを制作するコミュニティに所属しているプログラミングの初学者。目的は文法や課題に合わせた複数行のコードの組み方を勉強させ、簡単なゲームを作ることを目指す。
- git環境を最初に導入してもらうが、ひとまずGitHubとは連携しない。
